## 选择在线或本地模型

- **在线模型**：需要网络和自己的 API 凭证，音频会发送给所选服务。
- **本地模型**：先下载模型文件，之后在设备上识别；无需申请 API Key，但会使用本机内存和处理器资源。

支持语言、热词和流式能力见 [模型兼容清单](/zh/docs/compatibility)。

## 在线模型

1. 打开「设置 → 语音识别模型 → 在线模型」，选择提供商。
2. 按所选服务商的要求申请凭证；支持的服务及配置教程见 [模型兼容清单](/zh/docs/compatibility)。
3. 将凭证填入对应模型卡片并保存，再启用该模型。
4. 用快捷键录制一句话，确认收到识别结果。

## 本地模型

1. 打开「设置 → 语音识别模型 → 本地模型」。
2. 根据语言和设备资源选择模型，点击下载；所需的语音活动检测（VAD）及标点模型（Transformer）会按模型配置一起准备。
3. 等待下载完成，再启用模型。

## 自定义配置

在「设置 → 语音识别模型 → 自定义配置」中可调整以下高级设置。通常保留默认值即可；具体效果取决于模型及推理后端。单个在线模型还可能提供自己的参数，按对应服务的要求配置。

### 音频采样

- **音频采样**：每秒采集的音频样本数。修改前应确认模型或服务支持该采样率。
- **声道**：音频通道数。通常保留默认值，以满足模型或服务的输入要求。

### 识别强化

- **模拟流式输出**：让支持的离线模型根据语音停顿分段识别和显示文字；关闭后等待结束录音再识别。
- **热词强化**：控制是否向润色模型提供热词，可选择自动、关闭或开启。仅在使用润色时生效，详见 [热词库](/zh/docs/hotwords)。
- **热词替换**：将识别出的热词恢复为保存时的拼写和格式。

### 离线模型推理

- **线程数**：本地推理使用的计算线程数。增加线程可能提高速度，也可能增加资源占用。
- **推理后端**：选择本地计算方式；可用性取决于系统、设备和应用构建。
- **标点符号**：控制外部标点模型。自适应在识别模型不自带标点时使用；禁用不使用；强制启用则尝试使用，即使识别模型自带标点。需要标点模型已下载。
- **VAD 阈值**：语音活动检测（VAD）判断是否有人说话的阈值；调低通常更容易检测到声音，也更容易受噪声影响。
- **VAD 最小静音时长**：判定讲话间断所需的最短静音时间，单位为秒；较长的值可减少短暂停顿导致的切分，但可能延迟分段。
- **VAD 最小说话时长**：判定有效语音的最短时长，单位为秒；提高可过滤短噪声，也可能漏掉短语音。
- **VAD 最大说话时长**：单段语音的最长时长，单位为秒；较长的语音会被切分，调整会影响分段和识别效果。
