## 选择在线或本地模型

- **在线模型**：需要网络和自己的 API 凭证，音频会发送给所选服务。
- **本地模型**：先下载模型文件，之后在设备上识别；无需申请 API Key，但会使用本机内存和处理器资源。下载与推理设置见[本地语音识别模型](/zh/docs/local-models)。

支持语言、热词和流式能力见 [模型兼容清单](/zh/docs/compatibility)。

## 在线模型

1. 打开侧栏「模型服务」，展开需要的供应商；没有显示时，点击列表底部「显示其余」。
2. 支持多种能力的供应商先选择「语音识别」，在「接入凭证」填写对应信息。配置教程：[火山引擎](/zh/docs/api/volcengine)、[ElevenLabs](/zh/docs/api/elevenlabs)、[千问](/zh/docs/api/qwen)。
3. 点击模型行打开「模型配置」，保留默认参数，点击「测试」。被移除的预置模型可通过「添加模型」恢复。
4. 测试成功后，在模型配置中点击「设为默认」，或在页面顶部「语音识别」中选择该模型。
5. 到输入框使用快捷键录制一句话，确认实际录音与粘贴可用。

## 模型测试

「测试」使用内置音频样例请求所选识别模型，不切换当前模型。在线测试会向供应商发送样例音频，可能产生服务用量；本地测试在设备上运行。

「模型请求成功」表示这次样例请求成功，不代表麦克风权限、快捷键或自动粘贴已经验证。首次配置后仍需在其他应用的输入框完成一次真实语音输入。

## 自定义配置

点击「模型服务」中「供应商列表」右侧的齿轮，打开「自定义配置」，调整共用识别参数。通常保留默认值即可；具体效果取决于模型及推理后端。单个模型的参数通过点击模型行调整。

### 音频采样

- **音频采样**：每秒采集的音频样本数。修改前应确认模型或服务支持该采样率。
- **声道**：音频通道数。通常保留默认值，以满足模型或服务的输入要求。

### 识别强化

- **热词强化**：控制是否向润色模型提供热词，可选择自动、关闭或开启。仅在使用润色时生效，详见 [热词库](/zh/docs/hotwords)。
- **热词替换**：将识别出的热词恢复为保存时的拼写和格式。
