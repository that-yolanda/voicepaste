title: "火山引擎（豆包语音）"
---

本指南用于开通豆包语音识别，并将凭证填入 VoicePaste。

## 1. 开通语音识别服务

1. 登录 [豆包语音控制台的开通管理](https://console.volcengine.com/speech/new/setting/activate)。
2. 在当前项目中找到「流式语音识别 2.0」，按控制台提示开通。

   [![在豆包语音开通管理中开通流式语音识别 2.0](/assets/docs/doubao-config-new-service.png)](/assets/docs/doubao-config-new-service.png)
3. 检查服务状态和可用额度。费用、试用额度及是否需要充值，以当前控制台为准。

## 2. 创建 API Key

1. 打开 [API Key 管理](https://console.volcengine.com/speech/new/setting/apikeys)。
2. 确认选中开通服务的同一个项目，再创建或获取 API Key。

   [![在豆包语音 API Key 管理中创建或查看密钥](/assets/docs/doubao-config-new-key.png)](/assets/docs/doubao-config-new-key.png)
3. 保存密钥，用于下一步配置。不同项目的密钥和资源不能混用。

## 3. 填入 VoicePaste

1. 打开「设置 → 语音识别模型 → 在线模型」，找到火山引擎的豆包流式语音识别模型。
2. 在参数配置中填写 API Key。如果已有旧版凭证并显示「鉴权方式」，切换为「新版」。
3. 保留其他参数的默认值，保存配置并启用模型。

   [![在 VoicePaste 中填写豆包语音 API Key](/assets/docs/asr-doubao-new.png)](/assets/docs/asr-doubao-new.png)
4. 在输入框中录制一句话，确认文字输出。

## 已有旧版凭证时

旧版账户可以使用 `App ID` 和 `Access Token`。新用户优先使用前面的 API Key 方式，无需同时填写两套凭证。

1. 在 [旧版豆包语音控制台](https://console.volcengine.com/speech/app) 创建或选择应用，接入能力选择「豆包流式语音识别模型 2.0 小时版」。

   [![旧版豆包语音控制台创建应用并选择语音识别能力](/assets/docs/api-step1.png)](/assets/docs/api-step1.png)

2. 进入对应模型，选择应用并开通服务，获取该应用的 App ID 和 Access Token。

   [![旧版豆包语音控制台查看应用和认证信息](/assets/docs/api-step2.png)](/assets/docs/api-step2.png)

3. 在 VoicePaste 的模型参数中选择「旧版」鉴权，填写对应凭证并保存。

   [![VoicePaste 旧版鉴权中的 App ID 和 Access Token 配置位置](/assets/docs/asr-doubao-old.png)](/assets/docs/asr-doubao-old.png)

## 热词与更多参数

- **本地热词**：按 [热词库](/zh/docs/hotwords) 创建并启用词组。
- **在线热词表**：在 [热词管理](https://console.volcengine.com/speech/new/hot-word) 创建词表，再把词表 ID 填入模型的「热词表 ID」。
- **在线替换表**：在 [替换词管理](https://console.volcengine.com/speech/new/correct-word) 创建后，把 ID 填入「替换表 ID」。
- **其他参数**：确认基本识别可用后再调整；语言和方言支持随接口模式而异，不能直接套用其他接口的能力。
