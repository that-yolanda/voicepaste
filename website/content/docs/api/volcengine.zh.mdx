火山引擎的**豆包语音识别**与**火山方舟大语言模型**使用不同的服务入口，需要分别申请 API 凭证、开通所用模型的调用权限。VoicePaste 中也要分别填写两类凭证。

## 1. 语音识别模型

### 申请 API Key

1. 打开 [API Key 管理](https://console.volcengine.com/speech/new/setting/apikeys)。
2. 选择后续开通语音服务所用的项目，再创建或获取 API Key。

   [![在豆包语音 API Key 管理中创建或查看密钥](/assets/docs/doubao-config-new-key.png)](/assets/docs/doubao-config-new-key.png)
3. 保存密钥，用于下一步配置。不同项目的密钥和资源不能混用。

### 开通语音识别模型

1. 登录 [火山引擎语音控制台的开通管理](https://console.volcengine.com/speech/new/setting/activate)。
2. 在当前项目中找到「流式语音识别 2.0」，按控制台提示开通。

   [![在豆包语音开通管理中开通流式语音识别 2.0](/assets/docs/doubao-config-new-service.png)](/assets/docs/doubao-config-new-service.png)
3. 检查服务状态和可用额度。费用、试用额度及是否需要充值，以当前控制台为准。

### 配置 VoicePaste

1. 打开「模型服务 → 火山引擎 → 语音识别」，找到火山引擎的豆包流式语音识别模型。
2. 在「接入凭证」中填写 API Key。如果已有旧版凭证并显示「鉴权方式」，切换为「新版」。
3. 点击模型行打开「模型配置」，保留其他参数默认值，先「测试」再「设为默认」。

4. 在输入框中录制一句话，确认文字输出。

### 使用旧版 App ID 与 Access Token

旧版账户可以使用 `App ID` 和 `Access Token`。新用户优先使用前面的 API Key 方式，无需同时填写两套凭证。

1. 在 [旧版火山引擎语音控制台](https://console.volcengine.com/speech/app) 创建或选择应用，接入能力选择「豆包流式语音识别模型 2.0 小时版」。

   [![旧版火山引擎语音控制台创建应用并选择语音识别能力](/assets/docs/api-step1.png)](/assets/docs/api-step1.png)

2. 进入对应模型，选择应用并开通服务，获取该应用的 App ID 和 Access Token。

   [![旧版火山引擎语音控制台查看应用和认证信息](/assets/docs/api-step2.png)](/assets/docs/api-step2.png)

3. 从旧版升级并保留旧凭证时，在「火山引擎 → 语音识别 → 接入凭证」选择「旧版」鉴权，核对 App ID 与 Access Token。新安装若只显示 API Key，请使用前面的新版方式。

### 热词与更多参数

- **本地热词**：按 [热词库](/zh/docs/hotwords) 创建并启用词组。
- **在线热词表**：在 [热词管理](https://console.volcengine.com/speech/new/hot-word) 创建词表，再把词表 ID 填入模型的「热词表 ID」。
- **在线替换表**：在 [替换词管理](https://console.volcengine.com/speech/new/correct-word) 创建后，把 ID 填入「替换表 ID」。
- **其他参数**：确认基本识别可用后再调整；语言和方言支持随接口模式而异，不能直接套用其他接口的能力。

## 2. 大语言模型

### 申请火山方舟 API Key

登录[火山方舟控制台](https://console.volcengine.com/ark/region%3Acn-beijing/docs/api-key)，选择使用的项目并创建 API Key。方舟密钥用于文本模型，不要填写豆包语音服务的密钥。

### 开通模型并确认 Model ID

按[方舟官方快速入门](https://docs.volcengine.com/docs/ark/quick-start?lang=zh)开通需要的文本模型，检查额度，并确认控制台提供的 API 模型标识；需要推理接入点的模型使用对应接入点 ID。

### 配置 VoicePaste

1. 在「模型服务 → 火山引擎」切到「大语言」，填写方舟 API Key。
2. 基础地址保留 `https://ark.cn-beijing.volces.com/api/v3`，不含 `/chat/completions`。
3. 点击「添加模型」选择模型；列表不可用时，按控制台提供的 Model ID 手动添加。
4. 打开模型配置进行「测试」，成功后「设为默认」，再到[文本润色](/zh/docs/templates)添加模板并绑定快捷键。

## 3. 常见问题

### 为什么语音识别可用，文本润色却失败？

两类服务的凭证、模型授权与额度需要分别检查。语音服务开通成功，不代表火山方舟的模型已经可调用。

### 为什么看不到旧版鉴权选项？

应用仅在已有旧版凭证时显示对应选项。新配置优先使用语音控制台的 API Key；从旧版升级时保留原配置，再核对迁移后的 App ID 和 Access Token。

### 填入密钥后，语音识别仍然失败怎么办？

检查密钥与语音服务是否属于同一项目、模型是否已开通、鉴权方式是否匹配，并检查账户额度。更多排查见[在线识别常见问题](/zh/docs/faq#online-recognition)。
