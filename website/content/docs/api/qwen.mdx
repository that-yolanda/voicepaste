Qianwen AI and Alibaba Cloud Bailian both connect through **Model Services → Qwen**. Change the URL for your platform and use an API key obtained from that platform. Credentials are issued separately and are not interchangeable.

## 1. Prepare credentials

### Get an API key

1. Find your platform edition and region in the table below, open **Get API key** in that row, and follow its **Official guide**. Obtain credentials separately for each platform.
2. Check that the model is enabled, your key permits access, and quota is available. For Bailian, also confirm the region and workspace.
3. Enter a key separately in VoicePaste’s speech and language-model settings. A key with access to both capabilities on one platform can be entered in both places.

Bailian’s China site also supports Singapore: choose by account site and actual region, rather than treating Singapore as an international edition. Obtain credentials and copy endpoints from the same row. When changing platform, account site, or region, update both the API key and URL. For Bailian workspace domains, use the API Host shown in the console.

## 2. Speech recognition

1. Open **Model Services** and expand Qwen. Use **Show remaining** if needed.
2. Select **Speech recognition** and enter the API key and matching WebSocket URL under **Credentials**.
3. Choose a built-in model: **Qwen ASR 3.1 Message** supports dictation with optional filler removal and expression cleanup; **Qwen ASR 3.1 Streaming** supports continuous transcription and language hints. See the [official model guide](https://platform.qianwenai.com/docs/developer-guides/speech/speech-to-text-models).
4. Open the model row, keep default parameters, click **Test**, then **Set as default** after success.
5. Try real recording in another app's text field to confirm final text and pasting.

Plain **Voice input** inserts the recognizer's returned text directly. A template shortcut additionally processes it with the current language model. Message may already clean up the wording rather than preserving every spoken word.

## 3. Language models / text polishing

1. Select **LLM** within Qwen and enter that tab's API key and API base URL.
2. Click **Add model** and select a text model. If listing is unavailable, choose **Add a custom model** and enter an API Model ID from your platform.
3. Open the model row, click **Test**, then **Set as default**. Continue with [Text Polishing](/en/docs/templates) and a template shortcut.

Text URLs are base URLs without `/chat/completions` or `/models`. Do not use the speech `wss://` URL in text settings.

## 4. Common questions

- **Authentication or service errors:** match the platform edition, account site, region, and URL against the table, then check workspace, model access, and quota.
- **Model listing fails:** check the text base URL; manually add an API Model ID and test the actual request.
- **Tests work but voice input does not:** built-in samples do not test your microphone or paste permissions. Check [permissions](/en/docs/permissions) and [hotkeys](/en/docs/hotkeys).
