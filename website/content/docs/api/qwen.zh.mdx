千问与阿里云百炼都可通过「模型服务 → 千问」接入：按所用平台修改 URL，并填写在该平台单独申请的 API Key。两边的凭证相互独立，不能直接混用。

## 1. 准备凭证

### 申请 API Key

1. 在下表中找到使用的平台版本和地域，进入该行的「申请 API Key」创建密钥；操作步骤见同一行的「官方指南」。不同平台需分别申请凭证。
2. 检查所选模型是否已开通、密钥是否有对应模型的调用权限，以及账户是否有可用额度。百炼还需确认地域和业务空间。
3. 在 VoicePaste 的语音识别与大语言配置中分别填写 API Key。同一平台的密钥若有两种能力的权限，可以重复填写同一个密钥。

### 平台入口与连接地址

从同一行申请凭证并复制对应连接地址；更换平台、站点或地域时，同时更新 API Key 与 URL。百炼的业务空间专属域名以控制台显示的 API Host 为准。

## 2. 语音识别

1. 打开「模型服务」，展开「千问」；未显示时，点击列表底部「显示其余」。
2. 选择「语音识别」，在「接入凭证」中填写 API Key 和匹配的 WebSocket 地址。
3. 选择内置模型：**Qwen ASR 3.1 Message** 面向语音输入，可按模型设置去除口头语和整理表达；**Qwen ASR 3.1 Streaming** 面向持续转写，提供语言提示等设置。见[官方模型说明](https://platform.qianwenai.com/docs/developer-guides/speech/speech-to-text-models)。
4. 点击模型行，先保留默认参数并「测试」，成功后「设为默认」。
5. 到其他应用的输入框完成一次真实录音，确认最终文字和粘贴可用。

普通「语音输入」直接输出识别模型返回的文字；使用润色模板快捷键时，才继续交给当前大语言模型处理。Message 模型自身可能已经整理表达，不一定逐字保留口语。

## 3. 大语言/文本润色

1. 在同一供应商切到「大语言」，填写这一页的 API Key 与接口基础地址。
2. 点击「添加模型」，从可用列表选择文本模型。列表不可用时，选择「添加自定义模型」，按平台提供的 API Model ID 手动添加。
3. 点击模型行进行「测试」，成功后「设为默认」，再到[文本润色](/zh/docs/templates)添加模板并设置快捷键。

文本地址只填写基础地址，不含 `/chat/completions` 或 `/models`。不要把语音的 `wss://` 地址填到文本配置中。

## 4. 常见问题

- **鉴权或服务不可用**：按表格核对平台版本、站点、地域与连接地址，再检查业务空间、模型权限和账户额度。
- **模型列表加载失败**：检查文本基础地址；可以手动添加 API Model ID，再用「测试」确认实际请求。
- **测试成功但无法输入**：测试使用内置样例，不检查麦克风或粘贴权限，继续检查[系统权限](/zh/docs/permissions)与[快捷键](/zh/docs/hotkeys)。
