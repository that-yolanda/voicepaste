VoicePaste uses ElevenLabs Scribe v2 Realtime for live speech recognition.

## 1. Create an API key

1. Sign in to the [ElevenLabs API Keys page](https://elevenlabs.io/app/api/api-keys).
2. Create a key with a recognizable name, such as `VoicePaste`.
3. In the key permissions, set **Speech to Text** to **Access**.

   [![Allow Speech to Text access when creating an ElevenLabs API key](/assets/docs/elevenlabs.png)](/assets/docs/elevenlabs.png)
4. Store the generated key and check that your account has available quota.

## 2. Configure VoicePaste

1. Open Settings → Speech models → Online Models.
2. Find ElevenLabs — Scribe v2 Realtime, enter the API key, and save.
3. Enable the model and keep its default parameters initially.
4. Complete a voice input with a shortcut and check the recognized text.

## 3. Adjust recognition settings if needed

- Start with defaults for multilingual recognition, then adjust language options if needed.
- For names and technical terms, configure [Hotwords](/en/docs/hotwords) and check that the model's hotword option is enabled.
- The text confirmation setting controls when recognition text is committed. Keep the default if unsure.
