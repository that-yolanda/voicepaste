DeepSeek handles text translation and polishing in VoicePaste, not speech recognition. It is optional for plain transcription.

## 1. Language models / text polishing

### Get an API key

1. Sign in to the [DeepSeek platform](https://platform.deepseek.com/).
2. Open [API keys](https://platform.deepseek.com/api_keys), create a key, and store it.
3. Check the API account's balance and available services.

### Configure VoicePaste

1. Open **Model Services** and expand DeepSeek. Use **Show remaining** if needed.
2. Enter the API key under **Credentials**. Keep the base URL `https://api.deepseek.com/v1`, without `/chat/completions`.
3. Click **Add model** and choose an available model. If listing fails, manually add a supported API Model ID.
4. Open the model row, click **Test**, then **Set as default** after success. All text-polishing templates share the current language model.

VoicePaste appends `/chat/completions` or `/models` to the base URL. Do not enter a full request endpoint, website homepage, or console URL.

### Verify translation or polishing

1. In Text Polishing, add a template, such as “Translate to English,” and write its instruction.
2. Bind a shortcut to it in Hotkeys.
3. Say a sentence in an input field, finish with the template shortcut, and check the translation.

See [Language models and templates](/en/docs/templates) for the full flow. Saving a key alone does not verify an API call.
