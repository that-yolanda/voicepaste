本地语音识别模型在设备上处理音频，无需 API Key。首次使用需要下载模型文件，之后可离线识别；运行时会使用本机内存和处理器资源。支持的模型、语言和能力见[模型兼容清单](/zh/docs/compatibility)。

## 下载并选择模型

1. 打开「模型服务」，展开「本地语音识别模型」。
2. 根据语言和设备资源选择模型并下载；所需的语音活动检测（VAD）及标点模型（Transformer）会按模型配置一起准备。
3. 等待下载完成，点击模型行打开配置并「测试」，再「设为默认」。本地模型下载完成后才会出现在顶部可选列表中。

![新版模型服务与本地模型配置](/assets/docs/model-services-zh.png)

## 模型测试

下载完成后，点击模型行打开配置并「测试」。测试使用内置音频，在本机运行，不切换当前模型。

## 辅助模型

部分模型需要语音活动检测（VAD）或外部标点模型，所需文件会按模型配置一起准备。辅助模型不作为当前语音识别模型单独选择。

## 分段输出

SenseVoice、FunASR-Nano 和 Qwen3-ASR 等非原生流式模型可根据讲话停顿分段识别。需要时，在「模型服务」的齿轮「自定义配置」中开启「分段输出」；关闭后等待结束录音再识别。

## 高级设置入口

点击「模型服务」中「供应商列表」右侧的齿轮，调整共用推理设置；点击单个模型行可调整该模型的参数。通常保留默认值即可。

## 推理与语音检测参数

- **线程数**：本地推理使用的计算线程数。增加线程可能提高速度，也可能增加资源占用。
- **推理后端**：选择本地计算方式；可用性取决于系统、设备和应用构建。
- **标点符号**：控制外部标点模型。自适应在识别模型不自带标点时使用；禁用不使用；强制启用则尝试使用，即使识别模型自带标点。需要标点模型已下载。
- **VAD 阈值**：语音活动检测（VAD）判断是否有人说话的阈值；调低通常更容易检测到声音，也更容易受噪声影响。
- **VAD 最小静音时长**：判定讲话间断所需的最短静音时间，单位为秒；较长的值可减少短暂停顿导致的切分，但可能延迟分段。
- **VAD 最小说话时长**：判定有效语音的最短时长，单位为秒；提高可过滤短噪声，也可能漏掉短语音。
- **VAD 最大说话时长**：单段语音的最长时长，单位为秒；较长的语音会被切分，调整会影响分段和识别效果。
