## macOS

### 麦克风

1. 打开 VoicePaste 的「设置 → 通用设置 → 系统权限」。
2. 点击「麦克风」旁的「检测」，在系统弹窗中允许访问。
3. 返回 VoicePaste 设置页面，重新检测，确认权限旁显示勾选图标。

### 辅助功能

辅助功能权限用于把文字输入到其他应用。

1. 在「设置 → 通用设置 → 系统权限 → 辅助功能」点击「前往授权」。
2. 在系统的「隐私与安全性 → 辅助功能」列表中找到 VoicePaste，打开旁边的开关。
3. 返回 VoicePaste 设置页面，重新检测，确认权限旁显示勾选图标。

## Windows

### 麦克风

1. 在 Windows 设置中搜索「麦克风」，打开麦克风隐私设置，允许应用和桌面应用访问麦克风。
2. 返回 VoicePaste，在「系统权限」中点击「检测」。
