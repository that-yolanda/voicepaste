## Recording sound cues

1. Open Settings → Preferences → Sound Cues.
2. Enable or disable recording start and end sounds as needed.
3. To customize a cue, replace it with a local audio file.

Disabling sound does not change how recording shortcuts work.

## Keep clipboard

Completed voice input is pasted automatically into the focused input. This option controls what remains in the clipboard afterward:

- **On**: Keep the recognized text so you can paste it again.
- **Off**: Restore the text that was in the clipboard before the paste.

This does not switch between automatic and manual paste.

## Remove trailing period

Enable this to remove a trailing period before output. Disable it if you want to preserve it.

## Keep recordings

When enabled, recordings are kept for the most recent month. When disabled, only failed recordings are retained for retry. See [Local processing and privacy](/en/docs/privacy).

## Beta updates

Enable beta updates to receive test release notifications. Test builds can be unstable, so opt in only if you want to try them. You can upgrade to a newer stable release when available.
