## 1. 配置大语言模型

语音识别负责把声音转成文字，大语言模型负责翻译、整理或润色。只使用语音转文字时，无需配置这一项。

1. 打开「模型服务」，展开供应商；没有显示时，点击列表底部「显示其余」。支持多种能力时，切到「大语言」。
2. 在「接入凭证」填写 API Key 和接口基础地址。地址不含 `/chat/completions` 或 `/models`，应用会自动追加请求路径；预置供应商通常保留默认地址即可。
3. 点击「添加模型」获取可用模型列表并添加。列表获取失败或没有目标模型时，选择「添加自定义模型」，填写显示名称和供应商要求的 Model ID；不要用网页聊天模式名称代替 API 标识。
4. 点击已添加模型，按需设置参数并「测试」。测试使用内置文本，不切换当前模型；在线测试会请求供应商并可能产生用量。
5. 点击「设为默认」，或在页面顶部「大语言」中选择该模型。所有文本润色模板共用当前选定的模型。

配置示例：[DeepSeek](/zh/docs/api/deepseek)、[千问](/zh/docs/api/qwen)、[火山引擎](/zh/docs/api/volcengine#text-models)。其他服务见 [模型兼容清单](/zh/docs/compatibility)。

## 2. 添加润色模板

1. 打开侧栏「文本润色」，点击「添加」创建模板，也可以点击「模板」从模板库添加。
2. 填写容易辨认的模板名称，例如「翻译为英文」。
3. 填写具体处理要求，例如：

> 将输入翻译成自然的英文，保留原意，只输出翻译结果。

![新版文本润色模板配置](/assets/docs/text-polishing-zh.png)

## 3. 绑定并使用快捷键

1. 打开「快捷键」，为模板设置对应按键。
2. 在输入框中开始录音，按当前模式使用该模板的快捷键完成。
3. 确认输出符合模板要求。操作方式见 [快捷键与输入](/zh/docs/hotkeys)。
