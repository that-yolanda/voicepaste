## 基本使用

<span id="pricing" />

### VoicePaste 免费吗？使用模型是否需要付费？

VoicePaste 免费、开源，本地识别无需购买 API 服务。在线识别和润色使用你自己的 API 凭证，相关订阅或用量费用由你直接向服务商支付；使用前请检查平台当前价格与额度。

<span id="systems" />

### 支持哪些操作系统和处理器？

支持 macOS（Apple Silicon 与 Intel）和 Windows x64，请在 [下载页面](/zh/downloads) 选择对应安装包。本地模型的加速方式因模型与推理后端而异，详见 [模型兼容清单](/zh/docs/compatibility)。

<span id="first-use" />

### 第一次使用需要完成哪些配置？

可以跟随应用内的配置引导完成设置：Windows 需要允许麦克风访问；macOS 还需授予辅助功能权限。随后配置供应商并选择模型，在线模型需要申请对应的 API Key，再选择合适的快捷键即可。具体步骤见[快速开始](/zh/docs)。

<span id="offline" />

### 可以完全离线使用吗？

可以。先完成模型下载与配置，再分别选择[本地语音识别模型](/zh/docs/local-models)和在本机运行的本地大语言模型，即可离线完成语音识别与文本润色，音频、文字和配置均保存在本机。详见[本地与数据隐私](/zh/docs/privacy)。

## 安装与权限

<span id="microphone" />

### macOS 无法录音，或之前拒绝过麦克风权限，怎么办？

打开「系统设置 → 隐私与安全性 → 麦克风」，开启 VoicePaste 的权限，再回到应用重新检测。已授权但仍无法录音时，检查系统当前输入设备，以及麦克风是否被静音。

如果仍无法重新申请权限，先退出 VoicePaste，在终端运行以下命令，再打开应用重新申请：

```bash
tccutil reset Microphone com.yolanda.voicepaste
```

该命令只会重置 VoicePaste 的麦克风权限，不会直接授权。具体步骤见 [系统权限](/zh/docs/permissions)。

<span id="paste" />

### macOS 已识别出文字，但无法自动粘贴，怎么办？

在「系统设置 → 隐私与安全性 → 辅助功能」中开启当前安装的 VoicePaste；列表中没有时，从「应用程序」手动添加。结束录音前先点击可编辑输入框，再在应用的输入框中验证。如果连识别文字也没有，请同时检查 [识别配置](#online-recognition) 和 [麦克风权限](#microphone)。

「保留剪贴板」只决定自动粘贴后是否在剪贴板中保留结果，不是自动粘贴开关，详见 [更多配置](/zh/docs/sounds)。

<span id="reinstall" />

### macOS 重装后，为什么需要重新授权？

辅助功能列表中可能仍保留旧安装的条目。先检查当前应用的授权状态；无法自动粘贴时，在系统辅助功能列表中移除旧条目，重新添加当前安装的 VoicePaste 并开启权限，同时检查麦克风权限。步骤见 [系统权限](/zh/docs/permissions)。

<span id="windows-install" />

### Windows 安装时被 SmartScreen 拦截，怎么办？

Windows 版本暂未签名，安装时可能触发 SmartScreen 提醒。先确认安装包来自 [官网下载页面](/zh/downloads) 或 [GitHub Releases](https://github.com/that-yolanda/voicepaste/releases/latest)；确认继续安装时，点击「更多信息 → 仍要运行」。如果没有该选项，或设备受组织策略管理，请联系管理员，无需关闭整个系统的安全防护。

<span id="windows-permissions" />

### Windows 无法访问麦克风，或弹出防火墙提示，怎么办？

在 Windows 设置中搜索「麦克风」，打开麦克风隐私设置，允许应用和桌面应用访问麦克风。检查输入设备与静音状态，再回到 VoicePaste 重新检测。

防火墙弹窗出现时，先确认应用为 VoicePaste，仅在需要时允许该应用通过，无需关闭整个防火墙或随意开放端口。操作见 [Microsoft 防火墙说明](https://support.microsoft.com/en-us/windows/security/firewall/risks-of-allowing-apps-through-windows-firewall)。

## 模型与识别

### 模型列表获取失败，或测试成功但仍不能输入，怎么办？

检查 API Key、基础地址和服务权限。大语言模型的基础地址不含 `/chat/completions` 或 `/models`；列表不可用时可在「添加模型」中手动添加 Model ID。模型测试使用内置样例，只验证一次模型请求，不检查麦克风、快捷键或自动粘贴。

<span id="choose-model" />

### 在线模型和本地模型有什么区别，应该怎么选？

在线模型向所选服务发送音频，需要网络、API 凭证和可用额度；本地模型需要先下载，并使用本机内存与处理器资源。根据语言、电脑配置和隐私需求选择即可。支持的模型和功能见 [模型兼容清单](/zh/docs/compatibility)。

<span id="online-recognition" />

### API Key 填写后仍然无法识别，应该检查什么？

检查 API Key 是否有效、URL 是否正确、所选模型是否已在供应商平台开通调用权限，以及账户余额或可用额度是否充足。具体配置请参见[模型配置说明](/zh/docs/compatibility)。

<span id="model-download" />

### 本地模型下载失败，怎么办？

检查网络与可用磁盘空间，再到「模型服务 → 本地语音识别模型」重试。等待模型及所需辅助组件下载完成后再启用，步骤见[本地语音识别模型](/zh/docs/local-models)。仍失败时，请在反馈中提供模型名称与错误提示。

<span id="streaming" />

### 为什么不同模型的实时文字显示方式不同？

原生流式模型会持续返回识别结果；支持分段输出的本地模型会根据语音停顿分段识别。使用分段输出需在「自定义配置」中启用「分段输出」，文字出现时间与最终结果可能有所不同。详见 [模型兼容清单](/zh/docs/compatibility)。

<span id="hotwords" />

### 如何改善专有名词、英文缩写的识别效果？

创建热词组、添加词条并启用，同一时间只有一个词组生效。确认当前模型支持热词；使用 ElevenLabs 时还需开启模型的热词功能。热词强化可向润色请求补充词条，热词替换可还原保存时的拼写与格式。

热词是提示，不能保证每次准确；应用会适配各模型的热词格式，权重是否生效取决于所选模型的接入能力。调整后用短句测试，步骤见 [热词库](/zh/docs/hotwords)。

## 文本润色与快捷键

<span id="plain-transcription" />

### 只想语音转文字，可以关闭文本润色吗？

可以，使用普通语音输入快捷键即可，无需配置大语言模型。

<span id="templates" />

### 如何使用翻译、邮件撰写等不同场景模板？

先配置大语言模型，再添加或选择模板，并绑定快捷键。免提模式下，用全局主键开始、模板结束键完成；按住说话模式下，按住模板快捷键录音，松开后处理。模板统一使用当前选定的大语言模型。步骤见 [大语言模型与润色模板](/zh/docs/templates)。

<span id="recording-modes" />

### 按一下录音和按住录音有什么区别？

免提模式按一次开始、再按一次结束，无需一直按住；按住说话模式需按住快捷键 0.5 秒后开始说话，松开结束。两种模式都可以按 `Esc` 取消，本次内容不会输出。详见 [快捷键与输入](/zh/docs/hotkeys)。

<span id="shortcut-conflicts" />

### 快捷键没有反应，或与其他应用冲突，怎么办？

确认当前录音模式与已保存的按键，使用时按下完整组合，避免夹带其他按键；按住说话模式需达到启动时长。如果提示冲突或按键被其他应用占用，换一组按键，并在应用的输入框中验证。macOS 还需检查辅助功能权限。步骤见 [快捷键与输入](/zh/docs/hotkeys)。

## 隐私、资源与反馈

<span id="privacy" />

### 音频、识别文字和 API Key 会保存或发送到哪里？

配置（包括保存的 API 凭证）与历史记录保存在本机。在线识别向所选服务发送音频；在线润色发送文字、提示词，也可能包含热词，具体处理与留存规则由服务商决定。本地识别不代表在线润色也在本地进行。

录音留存受「保留录音」设置控制，关闭后仍会保留失败录音用于重试。日志保存在本机，不会自动上传；主动提交反馈时才会发送所选信息与附件。完整说明见 [隐私文档](/zh/docs/privacy)，请勿公开 API Key 或配置文件。

<span id="memory" />

### 本地模型为什么会占用较多内存？

本地识别需要在电脑上加载模型数据，并使用运行时缓冲区；占用随模型大小、推理后端和配置而变化，应用空闲内存不等于识别时内存。资源有限时可选择较小模型，或在接受在线服务数据处理方式的前提下使用在线识别。参考 [模型兼容清单](/zh/docs/compatibility) 和 [性能测试报告](https://github.com/that-yolanda/voicepaste/blob/master/docs/tests/performance-report.md)。

<span id="feedback" />

### 遇到问题时，如何提交反馈？需要提供哪些信息？

通过应用内反馈入口或 [官网反馈页面](/zh/feedback) 提交。建议提供应用版本、操作系统、模型或服务商名称、复现步骤和完整错误提示；按需附上相关日志或截图，需要回复时请留下联系方式。

提交前自行检查附件，遮挡 API Key 与私人信息，请勿附上录音或配置文件。也可使用 [GitHub Issues](https://github.com/that-yolanda/voicepaste/issues) 公开讨论，但内容对所有人可见。
