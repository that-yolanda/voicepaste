## 1. Configure a language model

Speech recognition converts audio to text. A language model translates, organizes, or polishes it. This is optional for plain transcription.

1. Open **Model Services** and expand a provider, using **Show remaining** if needed. Select **LLM** when the provider supports multiple capabilities.
2. Enter the API key and API base URL under **Credentials**. Omit `/chat/completions` and `/models`: VoicePaste appends the request path. Preset providers can usually keep their default address.
3. Click **Add model** to load and select available models. If listing fails or a model is missing, choose **Add a custom model** and enter a display name and the provider's API Model ID. A chat website's mode name may not be a valid API identifier.
4. Open the added model, adjust parameters if needed, and click **Test**. It uses built-in text without switching the current model. Online tests call the provider and may count toward usage.
5. Click **Set as default**, or select it under **LLM** at the top. All text-polishing templates share the current model.

Examples: [DeepSeek](/en/docs/api/deepseek), [Qwen](/en/docs/api/qwen), [Volcengine](/en/docs/api/volcengine#text-models). See the [compatibility list](/en/docs/compatibility) for other services.

## 2. Add a text template

1. Open **Text Polishing** in the sidebar. Click **Add** to create a template or **Templates** to browse the library.
2. Give it a recognizable name, such as “Translate to English.”
3. Write a specific instruction, for example:

> Translate the input into natural English. Preserve its meaning and output only the translation.

![Updated text-polishing template settings](/assets/docs/text-polishing-en.png)

## 3. Bind and use a shortcut

1. Open Hotkeys and set the template's keys.
2. Start recording in an input field and finish with that template's shortcut according to the current mode.
3. Check that the result matches your instruction. See [Shortcuts and input](/en/docs/hotkeys).
