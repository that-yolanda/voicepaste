## Choose a recording mode

Open Settings → Shortcuts to check the current bindings and choose a mode.

### Hands-free

1. Press the global main key to start recording.
2. Press it again to finish plain transcription. For translation or polishing, finish with the corresponding template's end key instead.
3. Wait for recognition and any template processing. The text is pasted into the focused input.

### Push-to-talk

1. Hold the corresponding shortcut for **0.5 seconds**, then speak.
2. Release the shortcut to finish recording.
3. Using a template's shortcut also processes the recognized text with that template.

Configure sound cues under [More settings](/en/docs/sounds).

## Change a shortcut

1. Find plain voice input or the desired template on the Shortcuts page.
2. Start recording its shortcut and press the key combination you want.
3. Finish setup and test the new shortcut in an input field.

Avoid extra keys when recording or using a shortcut. The complete configured combination must be pressed.

## Cancel and choose the output location

- Press `Esc` to cancel the current recording without output.
- You can switch apps while recording. Focus the destination input before finishing.
- In hands-free mode, the template end key determines how that recording is processed. See [Language models and templates](/en/docs/templates).
