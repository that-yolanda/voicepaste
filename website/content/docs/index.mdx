## 1. Download and install

1. Open the [VoicePaste download page](/en/downloads) and choose your operating system.
2. On macOS, choose Apple Silicon or Intel to match your Mac. On Windows, choose the x64 installer.
3. Finish installation, open VoicePaste, and go to Settings.

When you first open VoicePaste, follow the **setup guide** to configure permissions, a recognition model, and shortcuts. The steps below provide more detail whenever you need it.

**Windows users**: Installation may trigger a system security notice. See [FAQ](/en/docs/faq#windows-install) for help.

## 2. Grant system permissions

1. Open Settings → Permissions & configuration and click Allow or Check beside Microphone. Allow access when prompted.
2. On macOS, also grant Accessibility permission so VoicePaste can paste text into other apps.
3. Return to VoicePaste and check again and confirm a checkmark appears beside each required permission.

See [System permissions](/en/docs/permissions) for the full steps.

## 3. Configure speech recognition

A speech recognition model (ASR) converts audio into text. Choose either an online or a local model.

- **Online**: Choose an online model and obtain credentials from its provider. Expand the provider in Model Services, enter credentials, test the model, and select it as the current recognizer. See the [compatibility list](/en/docs/compatibility) for setup guides.
- **Local**: Expand Local ASR in Model Services, download a model, test it, and set it as default. No API key is needed.

See [Speech recognition models](/en/docs/models) for general setup, [Local speech recognition models](/en/docs/local-models) for downloads, and [Model compatibility](/en/docs/compatibility) for supported features.

## 4. Configure a language model (optional)

For translation or polishing, configure and select a language model under Model Services, then add a template under Text Polishing. Skip this step if you only need transcription.

Find supported services and setup guides in the [compatibility list](/en/docs/compatibility), then follow [Language models and templates](/en/docs/templates).

## 5. Set shortcuts and try your first input

1. Open Hotkeys, check the bindings, and choose hands-free or push-to-talk mode.
2. Focus an input field in any app and use your shortcut to start speech recognition.
3. **Hands-free:** press the main key to start, then press the voice input end key when finished. **Push-to-talk:** hold its shortcut for 0.5 seconds to start, then release it when finished. Check that the text appears.

See [Shortcuts and input](/en/docs/hotkeys).
