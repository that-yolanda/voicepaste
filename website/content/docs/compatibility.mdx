## Understanding recognition features

- **Streaming output** reports native streaming support: the current VoicePaste integration receives ongoing recognition results. Both Zipformer variants stream locally.
- **Segmented output** recognizes and displays SenseVoice, FunASR-Nano and Qwen3-ASR results in segments based on pauses. Enable Segmented output in Custom Configuration. This differs from native streaming.
- **Speech cleanup** removes fillers, repetitions, or disfluencies during recognition. Enable the model’s relevant setting; this is separate from language-model polishing.
- **Auto punctuation and number formatting** report the model’s own capabilities. Number formatting converts spoken numbers and dates into written forms. Results vary by language and settings. A separate local punctuation model can add punctuation without changing the recognizer’s own capability.
- **Hotwords** require support from both the model and its configuration. Enable the relevant keyterm setting for ElevenLabs. VAD and punctuation models are supporting components, rather than separate transcription services.
- **Doubao dialects** depend on the API mode and model version. The official documentation distinguishes bidirectional streaming from streaming input; capabilities vary between modes. Configure the service using its API documentation.

Online Qwen Message and Streaming differ from local Qwen3-ASR; see the [Qwen guide](/en/docs/api/qwen). Doubao text models use [Ark credentials](/en/docs/api/volcengine#text-models), configured separately from speech recognition.

## Online and local

Online recognition sends audio to your chosen service. Online polishing sends the text to be processed. To keep both on your device, use local recognition with local polishing, or turn polishing off.
