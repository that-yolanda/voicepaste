## 1. 下载并安装

1. 打开 [VoicePaste 下载页面](/zh/downloads)，根据操作系统选择安装包。
2. macOS 用户根据芯片选择 Apple Silicon 或 Intel 版本；Windows 用户选择 x64 安装包。
3. 安装完成后打开 VoicePaste，进入设置。

首次打开 VoicePaste 后，可以跟随应用内的**配置引导**完成权限、识别模型和快捷键等设置。下方提供各步骤的详细说明，方便随时查阅。

**Windows 用户请注意**：安装时可能出现系统安全提示，处理方式见[常见问题](/zh/docs/faq#windows-install)。

## 2. 开启系统权限

1. 打开「设置 → 权限与配置」，点击麦克风旁的「授权」或「检测」，按系统提示允许访问。
2. macOS 还需要开启辅助功能权限，用于将识别文字粘贴到其他应用。
3. 返回 VoicePaste，重新检测，确认所需权限旁显示勾选图标。

具体操作见 [系统权限](/zh/docs/permissions)。

## 3. 配置语音识别模型

语音识别模型（ASR）负责把声音转换为文字。在线和本地模型任选一种即可。

- **在线识别**：选择在线模型，按服务商要求申请凭证，在「模型服务」展开供应商，填写接入凭证，测试模型后选为当前使用。配置教程见 [模型兼容清单](/zh/docs/compatibility)。
- **本地识别**：在「模型服务 → 本地语音识别模型」选择模型，下载并测试后设为默认，无需申请 API Key。

选择与配置入口见[语音识别模型](/zh/docs/models)，下载步骤见[本地语音识别模型](/zh/docs/local-models)，支持范围见[模型兼容清单](/zh/docs/compatibility)。

## 4. 配置大语言模型（可选）

需要翻译、整理或润色时，在「模型服务」配置并选择大语言模型，再到「文本润色」添加模板。只需要语音转文字时可以跳过。

支持的服务及配置教程见 [模型兼容清单](/zh/docs/compatibility)，具体步骤见 [大语言模型与润色模板](/zh/docs/templates)。

## 5. 设置快捷键并完成首次输入

1. 打开「快捷键」，查看当前绑定，选择免提模式或按住说话。
2. 点击任意应用中的输入框，使用快捷键开始语音识别。
3. **免提模式**：按主键开始，说完后按语音输入的结束键。**按住说话**：按住对应快捷键 0.5 秒开始，说完后松开。确认文字出现在输入框中。

操作方式见 [快捷键与输入](/zh/docs/hotkeys)。
